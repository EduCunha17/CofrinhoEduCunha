# CofrinhoEduCunha
Desenvolvimento de um sistema em Java que simula um cofrinho virtual, permitindo adicionar e remover moedas de diferentes países, visualizar as moedas armazenadas e calcular o valor total convertido para reais. O projeto utiliza conceitos de programação orientada a objetos, especialmente herança, polimorfismo, classes abstratas e coleções de objetos.

Descrição do projeto

O projeto consiste no desenvolvimento de um sistema de cofrinho virtual utilizando Java. O objetivo é simular o armazenamento de moedas de diferentes países, permitindo gerenciar os valores e calcular o saldo total convertido para reais. O sistema aplica conceitos de Programação Orientada a Objetos (POO).

Linguagens e tecnologias utilizadas
- Java: linguagem principal utilizada no desenvolvimento.
- Eclipse IDE: ambiente recomendado para escrever e executar o código.
- Programação Orientada a Objetos: aplicação de herança, polimorfismo e classes abstratas.
- ArrayList: estrutura de dados sugerida para armazenar as moedas.
- UML: diagrama utilizado como referência para a organização das classes.
  
 Como funciona
O sistema apresenta um menu interativo no qual o usuário pode adicionar moedas de diferentes países, remover moedas específicas, visualizar todas as moedas armazenadas e calcular o valor total do cofrinho convertido para reais.

Como instalar ou executar
Para executar o projeto, é necessário ter o Java JDK e um ambiente de desenvolvimento, como o Eclipse IDE. Basta importar o projeto Java no Eclipse, localizar a classe Principal.java e executá-la. O menu do cofrinho será apresentado no console, permitindo a interação com o sistema.
